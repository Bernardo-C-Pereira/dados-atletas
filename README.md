💻</h1>

<p align="center">
    <b>Este é o segundo projeto de certificação do curso DEVstart do qual possuí a finalidade de criar uma aplicação capaz de receber informações de um atleta, bem como calcular parâmetros e exibi-los para o usuário através da linguagem JavaScript.</b>
</p>

<h2 id="technologies">💻 Linguagens utilizadas</h2>

- JavaScript

<h2 id="started">🚀 O que o projeto faz? </h2>

Ele recebe um objeto dentro de uma classe contendo os dados dos competidores e retorna ao usuário, através de uma função, uma tabela contendo o nome, idade, peso, altura, notas, categoria, IMC e sua média na competição (desconsiderando a maior e a menor nota). Fornecendo uma tabela conforme o exemplo abaixo:

<h3>Exemplo da tabela fornecida</h3>

```bash
Nome: Cesar Abascal
Idade: 30
Peso: 80 Kg
Altura: 1.7 m
Notas: 10, 9.34, 8.42, 10, 7.88
Categoria: Adulto
IMC: 27.68
Média válida: 9,25
```
